Typical pipeline command:

  nextflow run nf-core/rnastructurome -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.  
or `--helpFull`.  

Input/output options
  --input                                [string] Path to comma-separated file containing information about the samples in the experiment. 
  --outdir                               [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                                [string] Email address for completion summary. 
  --multiqc_title                        [string] MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

Reference genome options
  --fasta                                [string] Path to transcript FASTA file. 
  --gtf                                  [string] Path to transcript annotation GTF file. 
  --ensembl_base_url                     [string] Ensembl FTP base URL used when auto-resolving transcript FASTA. [default: 
https://ftp.ensembl.org/pub]  
  --ensembl_release                      [string] Ensembl release for transcript FASTA auto-resolution (`current`, `latest`, or release number like 
`114`). [default: current]  

Sample metadata options
  --sample_id                            [string]  Fallback sample ID for rows missing `sample_id`. 
  --method                               [string]  Fallback probing method for rows missing `method`. 
  --principle                            [string]  Fallback probing principle for rows missing `principle`.  (accepted: RT-stop, MaP, rt-stop, map) 
 
  --organism                             [string]  Fallback organism for rows missing `organism`, typically a Latin binomial such as `Homo sapiens`. 
 
  --chemical                             [string]  Fallback chemical probing reagent for rows missing `chemical` (e.g. `1M7`). 
  --RT_enzyme                            [string]  Fallback reverse transcriptase enzyme for rows missing `RT_enzyme` (e.g. `M-MLV`). 
  --pH                                   [number]  Fallback DMS reaction pH for rows missing `pH`. 
  --umi_pattern                          [string]  Fallback UMI pattern for rows missing `umi_pattern`. Supplying a pattern enables umi_tools extract 
before cutadapt.  
  --fuzzy_untreated_pairing              [boolean] When true (default), a treated group with no exact `sample_group`+`replicate` untreated match falls 
back to the untreated sample sharing the same sample_group base token (portion before the first `_`) 
at the same replicate — e.g. `MDA-MB-231_untreated_r1` can serve as control for 
`MDA-MB-231_MTX_treated_r1`. If a treated group still has no untreated after that, and exactly one 
untreated control exists anywhere else in the same reference, that single control is reused for it 
(with a warning) — e.g. one shared untreated backing several treated replicates. Set false to 
require exact matches; unmatched treated groups then proceed without an untreated control (scoring 
method 2 or 4). [default: true]  

Read trimming options
  --cutadapt_adapter_5p                  [string]  Global fallback 5' adapter sequence(s), comma-separated. If omitted and no per-sample adapter is 
provided, the pipeline defaults to AGATCGGAAGAGC. [default: AGATCGGAAGAGC]  
  --cutadapt_adapter_3p                  [string]  Global fallback 3' adapter sequence(s), comma-separated. If omitted and no per-sample adapter is 
provided, the pipeline defaults to AGATCGGAAGAGC. [default: AGATCGGAAGAGC]  
  --cutadapt_quality_only                [boolean] If true, skip adapter trimming and apply quality/length trimming only. [default: false] 
  --cutadapt_5quality                    [integer] Base quality threshold for 5' trimming (used for MaP; RT-stop is forced to 0). [default: 20] 
 
  --cutadapt_3quality                    [integer] Base quality threshold for 3' trimming. [default: 20] 
  --cutadapt_len                         [integer] Minimum read length retained after trimming. [default: 25] 
  --cutadapt_min_align                   [integer] Minimum adapter overlap required for trimming. [default: 3] 
  --cutadapt_trim_n                      [boolean] Trim terminal N bases. [default: true]
