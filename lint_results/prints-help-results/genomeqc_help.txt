Typical pipeline command:

  nextflow run nf-core/genomeqc -profile <docker/singularity/.../institute> --input samplesheet.csv --outdir <OUTDIR>

help message of that parameter will be printed.  
or `--helpFull`.  

Input/output options
  --input                       [string] Path to comma-separated file containing information about the samples in the experiment. 
  --outdir                      [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --email                       [string] Email address for completion summary. 
  --multiqc_title               [string] MultiQC report title. Printed as page header, used for filename if not otherwise specified. 

Pipeline mode options
  --kvalue                      [integer] k-mer size for meryl (merqury). [default: 21] 
  --container_engine            [string]  Container engine used to launch the interactive Shiny app. Only 'docker' and 'podman' are supported 
- Singularity/Apptainer does not work.  (accepted: docker, podman) [default: docker]  

BUSCO options
  --groups                      [string]  A string with NCBI taxonomic groups of the assemblies. Can be a comma-separated list. [default: 
all]  
  --busco_lineage               [string]  A flag to set the busco lineage. [default: hymenoptera_odb10] 
  --busco_lineages_path         [string]  A flag to set the BUSCO lineages directory (optional) 
  --busco_config                [string]  A path to a BUSCO config file (optional) 
  --busco_clean                 [boolean] Remove intermediate files 
  --min_buscos                  [integer] Minimum number of Complete BUSCOs a sequence must have to be counted as significant 
ortholog-containing sequences.  
  --skip_busco                  [boolean] Skip BUSCO. If run on genome only, it will also skip orthofinder. [default: false] 

Decontamination options
  --gxdb                        [string]  Path to FCS-GX contamination screening database. 
  --gxdb_manifest               [string]  Path to FCS GX contamination screening database 
  --ramdisk                     [string]  Path to RAM-backed tmpfs or ramfs location to store FCS-GX database 
  --save_cleaned_genome         [boolean] Save cleaned genome after decontamination with FCS-GX 
  --save_cleaned_adaptor        [boolean] Save cleaned genome after adaptor removal with FCS-GX 

Annotation options
  --val_tool                    [string] Tool for gxf validation.  (accepted: agat, gffread) [default: agat] 

Orthology options
  --ortho_version               [string]  OrthoFinder major version to run.  (accepted: v2, v3) [default: v3] 
  --save_orthofinder_results    [boolean] Publish orthofinder results. [default: true] 
  --save_longest_isoform        [boolean] Publish longest protein isoform fasta files. 

TIDK options
  --skip_tidk                   [boolean] Do not run TIDK. [default: false] 
  --repeat                      [string]  DNA string for tidk motif search 

Tree summary options
  --tree_scale                  [integer] Modifies scale of the tree plot in the tree summary, default value is '0.0005'. Useful if tree tips 
overlap with the concatenated plots. Very sensitive, increase/decrease by two-fold.  
  --tree_style                  [string]  Tree layout style for the tree summary plot.  (accepted: roundrect, ellipse, rectangular, 
circular) [default: roundrect]  
  --circular_rings              [string]  Circular layout only: which summary stats to draw as rings. 
  --quality_preset              [string]  Circular layout only: phylogenetic-group thresholds used to score the quality (traffic-light) rings. 
 (accepted: generic, vertebrate, insect, plant, fungi, bacteria)  
  --quality_thresholds          [string]  Circular layout only: override individual --quality_preset cut-offs. 
  --show_ring_values            [boolean] Circular layout only: print each value on its ring. [default: false] 
  --skip_plots_genome_anno      [string]  Skip these stat plots in the genome and annotation tree plot. [default: nseqs_plot] 
  --skip_plots_genome_only      [string]  Skip these stat plots in the genome only tree plot. [default: nseqs_plot] 

Save intermediate files
  --save_sorted_seqs            [boolean] Publish sorted fasta genome files from seqkit. 
  --save_validated_annotation   [boolean] Publish gff files validated by AGAT. 
  --save_assembly               [boolean] Publish genomes and/or annotations of user-supplied RefSeq IDs. 
  --save_extracted_seqs         [boolean] Publish extracted protein fasta files by GFFREAD. 
  --save_filtered_seqs          [boolean] Publish filtered fasta genome files from seqkit. 

TE annotation options
  --te                          [string]  TE annotation method to run. Use 'hite' for HiTE or 'repeatmasker' for the full RepeatMasker 
pipeline. Omit to skip TE annotation. 'hite' does not support -profile conda/mamba  - use `-profile 
docker`, `-profile singularity`, or `-profile podman` instead.  (accepted: hite, repeatmasker) 
 
  --is_plant                    [boolean] Set to true for plant genomes (passed to HiTE). 
  --curated_lib                 [string]  Path to a curated repeat library for HiTE. 
  --famdb_library               [string]  Path to pre-staged famdb h5 partition file(s). Accepts a single file path or a glob pattern (e.g. 
'/path/FamDB*'). Alternative to downloading via RM_db.  
  --famdb_lineage               [string]  Taxonomic lineage to filter repeat families from famdb (e.g. 'hymenoptera'). Omit to export all 
families.  
  --run_repeatmodeler           [boolean] Run de novo repeat discovery with RepeatModeler before masking. Disabled by default — RepeatModeler 
typically requires 24 CPUs and 24–48 h per genome. When false, only the curated famdb library is 
used.  
  --repeatmasker_speed          [string]  RepeatMasker sensitivity/speed mode. 'default' is most sensitive; 'q' (quick) is ~5x faster; 'qq' 
(rush) is fastest with lowest sensitivity.  (accepted: default, q, qq) [default: qq]  
  --RM_download_db              [boolean] Download h5 partition files from the URLs specified in RM_db. [default: false] 
  --RM_db                       [array]   List of URLs to DFAM h5 partition files to download. 
  --te_clusterer                [string]  Clustering tool used to dereplicate the repeat library before RepeatMasker. 'mmseqs' uses MMseqs2 
easy-cluster; 'linclust' (default) uses MMseqs2 easy-linclust (linear time, less sensitive); 'cdhit' 
uses CD-HIT-EST.  (accepted: mmseqs, linclust, cdhit) [default: linclust]  
  --te_cluster_identity         [number]  Minimum sequence identity threshold (0.0–1.0) for repeat library clustering. Passed as -c to 
CD-HIT-EST and --min-seq-id to MMseqs2. [default: 0.8]  
  --te_cluster_coverage         [number]  Minimum alignment coverage threshold (0.0–1.0) for repeat library clustering. Passed as -aS to 
CD-HIT-EST and -c (with --cov-mode 1) to MMseqs2. [default: 0.8]  

Generic options
  --multiqc_methods_description [string]          Custom MultiQC yaml file containing HTML including a methods description. 
  --help                        [boolean, string] Display the help message. 
  --help_full                   [boolean]         Display the full detailed help message. 
  --show_hidden                 [boolean]         Display hidden parameters in the help message (only works when --help or --help_full are provided).
