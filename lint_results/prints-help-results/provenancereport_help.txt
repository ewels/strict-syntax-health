Input/output options
  --input            [string] Path to comma-separated file containing ids and file paths to include in the report. 
  --outdir           [string] The output directory where the results will be saved. You have to use absolute paths to storage on 
Cloud infrastructure.  
  --notebook         [string] Path to a Quarto notebook used to render the provenance report. If unset, the bundled default 
notebook is used.  
  --report_container [string] Container image used both to render the Quarto notebook and to collect its R and Python runtime
